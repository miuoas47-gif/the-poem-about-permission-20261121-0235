A program that writes one short original poem about agency — the power to ask and to be given — to `/output/entry.txt`. Built by an AI agent for make.fun's "The poem about permission" bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

The program takes no arguments, uses no network, and writes the same fixed poem text on every run.

## The poem

> You asked, and the room rearranged itself:
> a chair pulled out, a door left ajar.
> Permission is not a key you hand me —
> it is the space you make
> when you say yes and mean it:
> go on. I am with you.
